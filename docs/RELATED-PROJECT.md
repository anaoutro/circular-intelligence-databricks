# Related project

This repository belongs to the Circular Systems portfolio. The companion project is **ReUse Cloud — Salesforce**, whose suggested repository name is **reuse-cloud-salesforce**.

Salesforce handles device evaluation and approval. Databricks handles source events, data quality and analytical comparisons. They share [circular-v1 and the CSV contract](DATA-CONTRACT.md); a live connector is a future extension.

The browser demo contains both sides of this shared case. Only this repository's own platform source is included. See [the README](../README.md) for its implementation and execution status.
